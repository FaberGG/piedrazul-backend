# Contexto del Sistema
## Organizacion y entorno

La **Red de Servicios Medicos de Piedrazul**, ubicada en el kilometro 5 via al Huila (Popayan), es una organizacion sin animo de lucro orientada a atencion en medicina alternativa.

Servicios principales:

- Terapia neural
- Quiropractica
- Fisioterapia

La atencion ocurre de lunes a viernes en la manana, con alta demanda diaria.

## Problema de negocio

Evolucion historica del agendamiento:

1. Atencion por llegada espontanea (sin sistema formal).
2. Agenda manual en hoja de calculo.
3. Software de escritorio para soporte administrativo.
4. Necesidad actual de evolucion a backend web moderno con seguridad y trazabilidad.

Dolores identificados en los procesos previos:

- Largas esperas y desorganizacion operativa.
- Duplicidad de informacion y errores humanos.
- Dependencia del personal para agendar por WhatsApp/telefono.
- Dificultad para planificar la jornada de medicos y agendadores.

## Para que se desarrolla este software

Este backend se desarrolla para:

- Centralizar y estandarizar la gestion de citas.
- Habilitar agendamiento mas eficiente y escalable.
- Mantener control de acceso por roles.
- Garantizar trazabilidad de operaciones criticas.
- Preparar capacidades de autogestion para pacientes (RF3).

## Para quienes se desarrolla

Usuarios objetivo del sistema:

- **Administrador**: configura sistema, gestiona usuarios y medicos.
- **Agendador de citas**: registra citas manuales y consulta agendas.
- **Medico/Terapista**: consulta su agenda y participa en agendamiento asistido.
- **Paciente**: agenda de forma autonoma (objetivo funcional RF3).

## Resultado esperado

Reducir friccion operativa del proceso de asignacion de citas, mejorar experiencia del paciente y aumentar la capacidad de organizacion del equipo clinico mediante una plataforma con arquitectura modular, segura y mantenible.
